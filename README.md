# 大肥鱼ai bot · feiyubot

> 一个跑在 QQ 上的机器人。她不是一段提示词，是十个模块分权、一本只增的账，和一套读时现算的状态。
> 代码由deepseek和gpt共同实现，本人只负责许愿（bushi），后续会继续更新。

*A personality architecture for a QQ chatbot: organs with disjoint write rights, an append-only ledger for everything outside her body, and state computed on read instead of stored and mutated.*

---

## 1 项目概述

这是一个 QQ 机器人的完整实现 —— 她的魂、心、脑、嘴、手、眼、耳、家，加上把这一切串起来的日子线。

它不是「一个角色扮演提示词 + 一层脚手架」。整个仓库只押一个判断：**人格不该是提示词里的形容词，而该是有边界、有所有权、能被 diff 的数据**。于是：

- **她是谁**写在一份人写只读的正文里（`plugin/organs/soul/`），程序只能读，不能改；
- **她此刻如何**是另一份程序写、人只看的状态（`plugin/organs/heart/`）；
- **她记得什么**只有一条写入路径（`plugin/organs/brain/store.py` 的 `ingest`），全仓没有第二个地方能写记忆；
- **她说了什么**以通道回执为准 —— 真发出去的那句才进记忆，被弃的稿不进脑。

### 三条规矩

| | 规矩 | 判据 |
| --- | --- | --- |
| **R1 分界** | 能以「一件东西」被指认的 → 进家；只能以「她此刻如何」描述的 → 留器官体内 | 「把那张画给我看」指得出来，进家；「她今天挺高兴」指不出来，留体内 |
| **R2 单真源** | 每个概念只有一处真源 | 魂是基线（人写、程序只读），心是偏移（程序写、人只看），脑又读又写；家只收物件，绝不存状态 |
| **R3 一天循环** | 醒（魂自检 + 扫家）→ 日（收进 → 判断 → 做出 → 痕迹落家）→ 夜（痕迹压成记忆，心被今天改掉一点） | 明日醒来仍是她 |

拿不准一个概念归谁：先试着指认它；再问一句「这里和那里不一致听谁的」—— 答不上来就是双真源，必须删一个。

## 2 实现功能

### 2.1 十个器官

先说清一件事：**叙事是「七器官 + 一个家」，代码是十个包**。多出的两个不是新器官 —— `mind` 是装配层（把魂/心/脑/嘴拼成一轮对话并调模型），`day` 是日子线（节律、日程、独处、主动开口、夜里收尾），两者都不自带状态。

| 器官 | 一句话 | 落到代码里是什么 |
| --- | --- | --- |
| `soul` 魂 | 她是谁：人写、程序只读 | 七件正文（自称/形象/性格底色/怕什么/喜欢什么/待人姿态/红线），带字数预算、原子写、唯一写路径、五道演化闸、醒时自检、完整变更史 |
| `heart` 心 | 她此刻如何 | 情绪两把尺（现时指数回落到基线，半衰 3 小时；基线慢漂回默认，7 天）+ 精力（0–100 的时间函数，醒着 −4/h）+ 出站三态（说/少说/不说）+ 拒聊记录 |
| `brain` 脑 | 她记得什么、怎么想 | 唯一写入路径 `ingest`、三层候选的字面召回（自建 bigram，不用 FTS5）、按桶配额的装包、**读时兑现的遗忘曲线**、人名录、回忆判官、夜间压缩 |
| `mind` 心念 | 装配一层 | 把魂文本 + 回想 + 最近几轮原文 + 恒定篇拼成提示词，调模型，落账。模型走 OpenAI 兼容端点，`urllib` 直连，不用 SDK。另持联网检索的判据与顺序（见 2.3） |
| `mouth` 嘴 | 怎么说 | 切分（一条一句，一泡最多两句，纯动作自成一体）+ 节奏（首条立即，之后按字数对数 + `sha256(seed+序号)` 抖动，**同一 seed 必得同一组间隔**，面板预览与实际发送一致）+ 条款闸 + 动作配额 + 表情延后选 |
| `hand` 手 | 做出什么 | **六个**具名动作（记事/完成/发图/画画/换口吻/查资料）+ 三层许可 + 一本只增手账 + 本地生图（画完自己看一眼再发）+ 手机上的浏览与提炼（回执区分「尝试过」和「确认做成」） |
| `eye` 眼 | 看得见、看得懂 | 按文字问题识图、缩图与 GIF 抽帧、只交观察**不落盘**、可回看近期旧图、B 站资料只读 |
| `ear` 耳 | 听 | 本地 `faster-whisper`（CPU/int8）转写、YAMNet 声源线索、手机音频采集；**唯一可选依赖，没装就自动缺席** |
| `home` 家 | 身外之物 | 十间固定房（不许新建）+ 物件/痕迹/场景三分 + 两道门与上限 + 只增的审计账 + 索引卡 + 素材仓库与表情包 |
| `day` 日子 | 没人找她时她在干什么 | 60 秒一次的单一节律 tick（排当天日程、数到点、夜里四步收尾、算下一次时刻）+ 独处判据 + 主动开口的五个驱动源 + 成长判断 |

### 2.2 三道横切面

- **HTTP API**：`plugin/api/` 一张聚合路由表（`core.py` 的 `ROUTES`，同名键重复注册当场抛错）。看魂、看心、看脑、干跑嘴、读写家、驱动日子、一轮对话 `/chat`、回执 `/chat/ack`。敏感表只读，非 `GET` 一律 405。
- **Web 面板**：40 个页面文件，起核后浏览器打开 `/panel`。时间线、记忆星图、成长版本、模型提示词与原始回包、参数前后值都在这里看。
- **两条通道**：`channels/onebot/` 是主力（OneBot v11 反向 WS，一条消息进来先过「定向必回 / 闲聊抽样」的第一层判断，没抽到**一次核都不调**）；`channels/nonebot/` 是成熟协议适配器，只接线，人格与判断全留在原位。
### 2.3 一条跨器官的链：联网查一次

「这一轮该不该查、查什么」不是一个模块能单独拍的事，所以它被拆成四段，每段只做一件：

| 段 | 在哪 | 只管什么 |
| --- | --- | --- |
| 判据 | `plugin/organs/mind/search.py` | 六道门裁决「要不要查、查什么」。不联网、不落盘、不认聊天上下文 |
| 网络 | `plugin/organs/hand/lookup.py` | 拿一句公共 query 去查，只把结果规范化，不落卡、不记账 |
| 落卡 | `plugin/organs/home/knowledge.py` | 带来源的外部知识进家·仓库。字幕任务与网页任务同构同一容器 —— 分成两个容器就等于给「这张卡算不算事实」留两个答案 |
| 顺序 | `plugin/organs/mind/lookup.py` | 只负责把上面三段按对的顺序叫一遍 |

这条链也解释了一条硬规矩：**网络只许长在登记过的模块里**。`plugin/organs/hand/tests/test_source_rules.py` 里有一份 `NETWORK_FILES` 名单守着这件事，新代码想联网必须先上名单。

## 3 实现逻辑简述

### 3.1 一轮对话从哪里开始

| # | 在哪 | 做什么 |
| --- | --- | --- |
| 1 | `channels/onebot/server.ts` | NapCat 反向 WebSocket 接入 |
| 2 | `channels/onebot/parse.ts` | OneBot 事件 → 内部形态（心跳/生命周期只记数） |
| 3 | `server.ts` `ingest` | 入段：按 key 判重（同一条只收一次），引用先解析，落一行账 |
| 4 | `server.ts` `runSegment` | 攒批窗口到点，取出一段 |
| 5 | `channels/onebot/direct.ts` | 第一层决策：命令/纯表情/纯图硬拦；定向（私聊、@、引用她、外号）一定回；闲聊按序号抽样，没抽到这次不送核 |
| 6 | `server.ts` → `POST /chat` | 送核 |
| 7 | `plugin/api/core.py` → `chat.py` | 路由表分发 |
| 8 | `plugin/organs/mind/conversation.py` | 装配一轮：取魂文本、回想记忆、拼提示词 |
| 9 | `plugin/organs/mind/llm.py` | 调模型（OpenAI 兼容，`urllib` 直连） |
| 10 | `conversation.py` → `brain/store.py` | 落账：先记人的原话，她被确认发出去的那句再记；最近几轮另存一层 |
| 11 | `conversation.py` → `organs/mouth/` | 分泡与节奏：切在哪、隔多久 |
| 12 | `plugin/api/chat.py` | 出站闸先于一切：判「不发」就直接空回包 |
| 13 | `channels/onebot/bubbles.ts` | 通道侧再切一道：换行=换泡，超长只在标点处切，切完逐字节等于原文 |
| 14 | `channels/onebot/outbox.ts` | 严格串行发送，泡间按算好的时刻等，`ack` 超时兜底 |
| 15 | `POST /chat/ack` → `mind/delivery` | 回执闭环：只有通道确认的文本才进自述记忆 |

### 3.2 五套机制，各一段

- **记忆怎么存**：唯一入口 `brain/store.py` 的 `ingest`，今日追一条原文（逐字引用 + 可为空的注解 + 状态与行同时落盘），长期档只从「今日换日」降级而来。夜里 `run_night` 做压缩。
- **记忆怎么取**：`brain/recall.py` 在今日/长期/热记忆三层候选上做**字面**打分（子串 + 自建 bigram，同人 +2.0、今日 +0.5），再按桶配额装包。向量只做重排，**永不 gate**；遗忘是读时结算，不物理删、只标状态。
- **状态怎么维护**：心与精力**都不是定时器**，全是读时现算 —— 心情指数回落、基线慢漂、精力按 5 分钟切片积分，读到哪算到哪，落盘即结算，重启不重复扣。两者在 `heart/effective.py` 合成唯一读数，档位词、要不要说话、嘴的语气都只从这里取。
- **自主行为怎么触发**：`day/rhythm.py` 的 `tick` 是唯一定时器（默认 60 秒），起在 devserver 的守护线程里。主动开口有两处判据（五个驱动源各一个理由码；独处按「多久没人说话」三档），到点后**复用同一个 `/chat`**，只多一个由头 seed，出站闸与拒绝三关一个字不改。自主动作只调具名执行器，不接受路径、账号或任意工具名。
- **像人靠什么**：切分、节奏、动作、表情四件事分开做，互不越界 —— 切分只管切在哪，节奏只管隔多久，动作只识别括注里的环境词并不许编场景，表情在文字定稿后**才**选，且不改写回复。

### 3.3 四条贯穿全仓的约定

1. **读时结算，没有状态机在跑**：心情、精力、遗忘、静默时长全是读的时候现算。少一个定时器，就少一类漂移。
2. **唯一写路径**：记忆只有 `ingest`，魂只有一条写路径。想改状态，绕不过这两处。
3. **条款不进代码**：嘴的拦截条款、手的许可、家的房名与上限，全部是 `data/*.json` 里的数据。改判据 = 改数据，能 diff、能回滚，代码里一条条款都不写。
4. **网络只许长在登记过的地方**：能上网的模块是一份显式名单，由测试看住。想联网先改名单，让它在 diff 里可见。

## 5 快速开始

```bash
git clone <repo-url> && cd NewQQAgent
```

**配模型 key**（`home/.env`，这个文件不入库）：

```bash
printf "QQAGENT_LLM_KEY=sk-...\n" > home/.env
```

查找顺序是 `.env` 优先、环境变量兜底（`$QQAGENT_HOME/.env` → `<仓库>/home/.env` → 同名环境变量）；key 缺失时直接报错，绝不静默返回空串。模型名与地址在 `plugin/organs/mind/data/llm.json`。

**起她**：

```bash
./start-her.command        # 会先问一句「要不要她真的说话」，也可以传参：./start-her.command send
./stop-her.command
```

这一条命令串起四件东西：核（`plugin/` 里的 HTTP 服务，默认 8787）、业务通道（Node 直跑 `channels/onebot/server.ts`，默认 6200）、NoneBot 适配器（可选，6290）、NapCat（QQ 协议端，WebUI 6099）。停的时候反着收摊。

**跑测试**：

```bash
cd plugin && python3 -m unittest discover -s . -p "test_*.py"
cd channels/onebot && node --test
cd shell && npm test
```

**看面板**：起核之后浏览器打开 `http://127.0.0.1:8787/panel`。

环境要求：Python 3（核只要标准库）；Node ≥ 22.16（通道与壳）。语音转写需要另装 `faster-whisper`，不装则耳这项能力自动缺席，其余不受影响。

## 6 未实现功能说明

诚实清单，按「要不要做」分成三堆。

### 6.1 正在做（判据已定，唯一在途主线）

| 缺什么 | 现在的表现 |
| --- | --- |
| **自然度未通过** | 普通分享会被说成建议、会无依据认错、会把她没看到的细节写成「缺失」。这是当前唯一的主线问题 |
| **自动事实退役** | 旧说法挤不掉新更正，只能靠人工 |
| **逐人关系模型** | 有人名录和按人回读，但没有逐人态度、没有和解状态机 —— 还不是完整的「关系」 |
| **视频整段理解** | 只理解实际采样的几帧 |
| **说话人分离** | 耳只出平和/急/低三档，判不出人数、音色、语气 |
| **面板覆盖度** | 未覆盖全部参数，也不记手改文件的历史 |
| **生成期竞态守卫** | 生成中来新消息，会先发旧答案 |

### 6.2 仅计划（有设计，没开工）

- **自主维护**：让她自己读健康/日志/配置，在隔离副本里改自己、验收、留差异与回退。目标形态与实施顺序已定，未实施。
- **成长 B/C/D 批**：B（经历推动成长）隔离闭环验证过但长期未观察；C（个人打算）内容偏单一；D（搜索、收藏、评论、发帖等社交与探索扩展）未做。
- **抖音等价自主链**：安装与入口已确认，评论私信未开放；贴吧后置。
- **记忆星图的产品前端**：现在只有设计可视化，六层渲染/旋转/缩放没做。
- **日记 / 梦 / 自画像**：日记与梦有成功记录，自画像没有交付痕迹，状态待确认。

### 6.3 明确不做

- **红级权限永久不给**：钱、账号、身份这三类动作，不给。发说说、在群里主动开话题永远排在最后，且默认先出草案。
- **不用 QQ 官方 Bot API**：它只推被 @ 的消息，没有潜水听群的能力。
- **不给记忆加向量门**：向量只做重排，永不决定取不取；遗忘不物理删，只标状态并进查询条件。
- **不自研画图算法、不逆向平台接口、不做视频合成**：手只「使用工具」。
- **魂不自学习**：魂是人写的基线，程序只读；自学习发生在脑的自述层，不回头改魂。
- **家不存状态**：不新增「当下状态」房间 —— 状态不可指认，违反 R1；家只收物件，违反 R2。
- **不引入人格向量库、目标树、多 agent 人格委员会、奖励训练**：这些都被逐条否过，理由在代码与设计记录里。

## 7 展望

**自主生活五步**（当前进度）：

| 步 | 目标 | 状态 |
| --- | --- | --- |
| ① | 真实活动基础（双平台浏览） | 在跑 |
| ② | 活动决策与经历账 | 在跑 |
| ③ | 记忆与分享决策 | 在跑（主动分享已授权开启） |
| ④ | 自我诊断入口（只读健康/日志/配置） | 未开工 |
| ⑤ | 自我修改试验（隔离副本内改、验收、差异与回退） | 未开工 |

**最终形态**：一套完整插件 + 一个 WebUI 页面，人在页面上随时看、随时调。宿主接 DeepSeek Harness —— 壳可以换，核只有一份，不许复制。

**什么算做成了**：一个动作做完的标准，是**从一句话能触发**。她说「我给你画一张」，图上要有东西；她说「我记下了」，手账里要真有那一行；她承诺明天做，明天要真去。做不到这三件的「像人」，都还是表演。
