# pages/ —— 面板页

`soul.html`：零依赖（纯 HTML + 原生 JS）的魂面板，人的唯一写入口。

- 上半屏只读：名字／三句自述／待人姿态／红线（每条带执行方）+ 合计字数 / 1000（硬线；单件显示的是建议值）。
- 只有两处可写：待人姿态（stance 一句 + 原因）、接受提案（粘 JSON + 原因）。
- 右栏显示 `GET /soul/render`：她此刻会被注入的样子，改完不重启就变（矩阵归脑，不再分档）。
- 顶部两个链接指向心与脑的只读页（`/heart`、`/brain`）：链接是入口，不是写口。
- 页面上没有改心、改脑的任何控件或按钮；只读区那行说明就是这个意思。
- 顶部写明：无鉴权，只许绑 127.0.0.1。

`heart.html`、`brain.html`：心与脑的只读页，零依赖、无脚本。

- 标题写清「心 · 只读」「脑 · 只读」，正文一行「未接入：这一层还没有代码」。
- 没有 button / form / textarea / input，也没有任何发写请求的 JS。
- 一行说明引用 `architecture.md` §9.2：心与脑只能看，人不能改。

本地看：`python3 -m api.devserver --root organs/soul/data --port 8787`，打开 http://127.0.0.1:8787/ 。

后端契约在 `api/api.py`（六个魂端点 + 两个只读页）；给壳的挂载点在 `api/panel.py` 的 `routes(store)`。
