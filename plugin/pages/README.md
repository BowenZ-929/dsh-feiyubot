# pages/ —— 面板页

`observe.html`：地址保留记录来源、模型日期或回合、分页和本页关键词。刷新记录保留当前页；切换来源/日期/回合回到第一页。回合详情为原生链接，可用浏览器后退回到先前对话页；筛选通过 `panel-routechange` 通知同源外壳同步地址。关键词仅过滤已载入的20条，饭账日期独立。

聊天记录将QQ回执确认文字与底稿分开，缺回执/无关联/读取失败各自说明；本页搜索包括回执文字。成功只确认已有回执的部分，空文字不推断整轮失败，不按时间猜旧回合关联。

`settings.html` 顶部提供只读核心状态与手动刷新。`source_changed` 比较启动时/当前 Python 源码，`stale` 仅比较提交，`dirty` 仅表示未提交改动；版本信息默认折叠。读取失败隐藏旧详情，旧核心未提供字段时明确未知。家页页脚沿用同一状态含义。

明暗样式默认随系统，页面显式 `data-theme="light"/"dark"` 可覆盖；颜色继续优先取 `--dsw-alias-*`。星图的工具栏、详情和索引使用页面颜色，仅绘图区保留夜空背景。当前未实现跨 iframe 的宿主主题变量同步。

`panel.html`：七个主入口的总面板。子页跳转会同步当前栏目与地址，例如 `/panel#/galaxy`；刷新、后退和前进保留对应页面，URL已有查询参数和锚点一并恢复。星图归记忆，其余能力子页归设置；原页面仍可独立打开，不保存表单草稿。

`galaxy.html` / `galaxy.js`：真实记忆星图。入口在记忆页和设置页；搜索、拖动旋转、缩放、点选关系，支持列表及冷库/退役状态。只读 `/api/graph/snapshot` 与 `/api/memory/<节点编号>/why`，页面可见时每 5 秒刷新；只有数据版本变化才重建列表。Canvas2D 不可用时显示列表，不依赖 CDN。布局/投影适配 `dsh-Memory-Galaxy`，许可见同目录 `galaxy-REFERENCE-LICENSE.txt`；空间位置不表示语义或因果，只有已记录的边才连线。

`soul.html`：零依赖（纯 HTML + 原生 JS）的魂面板，人的唯一写入口。

- 上半屏只读：名字／形象／三句自述／怕什么（只显示，改不了）。
- 可写三处：待人姿态（一句 + 原因）、红线（逐条加／逐条撤，各带原因）、
  「她提的改动」里那条提案的「接受」。**拒绝不发请求**——她那边一个字都不动，也不记账。
- 「改动记录」底部一颗「退回上一版」：整档回滚，点前弹确认写明回到哪一版。
- 右栏显示 `GET /soul/render`：她此刻会被注入的样子，改完不重启就变（矩阵归脑，不再分档）。
- 只读块标题右边一行小字写着「由程序写：…」：程序写的东西只显示，不灰化。
- 页面上没有改心、改脑的任何控件或按钮。
- 顶部写明：无鉴权，只许绑 127.0.0.1。

`heart.html`：心的只读页，零依赖、无脚本。

- 标题写清「心 · 只读」，一行说明引用 `architecture.md` §9.2：心只能看，人不能改心。
- 没有 button / form / textarea / input，也没有任何发写请求的 JS。
